## 环境坑（重要）

- 系统 PHP 是 macOS 内置 7.3.24，`PHP_VERSION` 常量被污染成 "7.3.24-(to be removed in future macOS)"，导致 **Composer platform_check 之外的 PHPUnit 入口直接 die**（`version_compare(PHP_VERSION, PHP_VERSION, '=')` 失败）。
- 绕过办法：不用 `vendor/bin/phpunit`，改用 runner 脚本 `require vendor/autoload.php; PHPUnit\TextUI\Command::main(false)` 直接跑（platform_check 只用 PHP_VERSION_ID 整数，安全）。
- brew install php 失败（/usr/local 目录属主需 sudo）；Docker Hub 拉取失败（网络）。
- `php artisan serve` 本身可以跑（artisan 入口无 version_compare 检查）。
- 本机 macOS 11.3：agent-browser 自带 Chrome 154 起不来（缺 LocalAuthenticationEmbeddedUI），系统 Chrome 138 可用 `--headless --no-sandbox --disable-gpu --disable-dev-shm-usage` 截图验证。

## 预约大屏二次返工（矮窗口适配）
- 根因：左侧栏缺 min-h-0，号牌（旧字号按 vw 计算，宽屏下巨大）把 grid 行撑高 → 放号按钮被顶出屏幕（body overflow-hidden 无法滚回），右侧面板被连带撑出可视区导致号票区滚不动
- 修复：main/左栏加 min-h-0；.ticket-shell 加 min-h-0 overflow-hidden（超高只裁剪号牌区）；号牌字号改 clamp(6rem,30vh,16rem) 按视口高度缩放；records section 加 overflow-hidden，网格加 pb-3/pr-3 边距
- 验证：CDP 脚本 /tmp/cdp_verify.mjs 在 1920x1080/1600x900/1366x768/1280x720 四档尺寸断言：按钮底部在视口内 + 网格 scrollHeight>clientHeight 且可滚动
