## 修复：两个入口号票面板不一致（localStorage 数据源 bug）
- **根因**：「我的号票」面板渲染 localStorage records——① localStorage 按 origin 隔离，localhost 与 192.168.2.7 各自只存本机取过的号，列表天然不一致；② 本地 is_finish 只在本浏览器放号时更新，别处放号后永远过期（localhost 那个"已放号 1"就是这么来的）
- **修复**：state() 增加 `tickets` 字段（当前批次 [{serial_no,is_finish}] 升序）作为面板唯一数据源；store 选中态 selectedId→selectedSerial，release 用 state.batch_no+selectedSerial；localStorage records 降级为「本机」角标（isMine）；面板改名「当前号票」；换批后轮询自动清失效选中
- **坑**：改 state() 时顺手用了 `fn()=>` 箭头函数 → 运行时 PHP 7.3 直接 ParseError 500，**本机 PHP 7.3 禁用 7.4+ 语法**，改回传统闭包。AGENTS.md 技术栈表与坑位表都已修正
- **验证**：ReserveStateTest 补 2 个 tickets 用例（8 用例全过）；CDP 双 origin（localhost / 192.168.2.7）+ 脏 localStorage 注入复验，两边 tickets 完全一致，已放号置灰正确
