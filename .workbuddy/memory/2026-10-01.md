## 新增创建 Post 接口
- `app/Http/Controllers/Api/PostController.php` 实现 `create(Request $request)`
- 路由：`POST /api/posts`（公开）
- 参数：`title`（required|string|max:255）、`content`（required|string）
- 响应沿用 `{code, message, data}`；成功 201，校验失败 422 + `errors`
- 原 `posts` 表只有 id/时间戳，新增迁移 `2026_10_01_221600_add_title_and_content_to_posts_table.php` 加 `title`/`content`
- 坑：SQLite 不允许 `ALTER TABLE ADD COLUMN` 加“非空且无默认值”的列，必须 `->default('')`；且 SQLite 不支持 `after()` / `comment()`
- `Post` 模型补充 `$fillable = ['title','content']`
- curl 实测：201 创建成功并落库，422 校验拦截正常。测试数据 id=1 保留在 sqlite 中
